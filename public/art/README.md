# World art

threshold-environments-v3.png contains ten side-view city regions in two columns and five rows. The renderer caches each region at the pixel grid and layers actors, collision geometry, lighting and foreground silhouettes above it.

pilgrim-v6.png contains 32 transparent character poses. enemies-v7.png contains four enemy kinds across four combat poses. terrain-v7.png contains carved stone, iron, timber and root fragments.

Original image files stay unchanged. Runtime alpha isolation packs separate drawings into collision-aligned atlases. A background image is separate from playable level geometry.

# 0.6.0 — feral pilgrim and quiet title

The title no longer presents numbered website rows and an enlarged player on a pedestal. Four plain commands sit under engraved Cormorant SC lettering over the approved city painting. Credits, fullscreen and native Exit remain accessible. Chapters, story, journal and pause use the same heading language. Landscape settings put categories beside controls so the sliders, sound test and footer remain reachable; portrait retains comfortable touch targets.

Noir is now a detailed feral cat with a torn mantle, long tail, articulated paws and separate poses for running, jumping, rolling, striking, landing, hurt, death and wall contact. The generated source sheet is preserved; runtime masking isolates every drawing without neighboring tail bleed. Gait follows distance, and new claw traces replace the single blade arc. Asset failures use a local fallback.

The ten chapters, thirty sealed encounters, mandatory seal climbs, gravity, interpolation, story, three endings, memories, creator links, mobile controls and native app features remain. The sampled-instrument music is unchanged. This release addresses title/menu composition and character art; it does not claim parity with the reference studios. See [character production and research](CHARACTER_V6.md).

Physical phone/controller testing and human listening, difficulty and art approval remain outstanding. Android downloads are debug-signed test builds; no iOS binary is provided.

Local validation: 52 simulation/input/campaign checks and nine browser checks passed. The official Windows Electron development shell passed fullscreen/F11, story, movement, jump, pause, settings, credits and actual native quit. Offline playback loaded 58 cached resources, including the new character and all eight font files. Rendered title/settings/story views were inspected at desktop, portrait and landscape sizes; independent review found no remaining actionable defects after the short-screen layout and asset-loading fixes. Packaged Windows execution was not tested on this machine.

# Noir: feral pilgrim

The previous character used a small procedural humanoid mask and rigid limbs. It was readable but did not belong beside the detailed environment paintings. The replacement is a quadrupedal cat with articulated hocks, a narrow muzzle, expressive tail, torn mantle, pale scars and a broken circular collar charm. There are no crosses or borrowed game characters.

The transparent source `public/art/pilgrim-v6.png` was generated with the built-in imagegen tool on 2026-10-09. It is a generated asset directed and inspected for this game, not a claim of hand drawing or studio animation. The original PNG is preserved unchanged. Its 32 disconnected drawings are isolated by their alpha components at startup, then packed into 192×160 animation cells with a shared floor pivot. This avoids cutting off long tails or importing neighboring drawings from the uneven source grid. It is packed once, not during gameplay. A missing or invalid sheet uses the bundled procedural fallback.

Two idle drawings, sixteen stride drawings, rising/falling jumps, four rolls, three strikes, landing, hurt, death and wall poses replace the previous normal character. The additional idle drawing is retained in the atlas. Gait timing follows distance traveled; physics and interpolation remain unchanged. Three claw traces accompany strikes. Torch tint, contact shadows, pixel sampling and dash trails use the new atlas.

## Production study

- [Team Cherry's Hollow Knight production case study](https://unity.com/made-with-unity/hollow-knight): traditional sprite animation, simple layered lighting and a deliberate drawing workflow. Applied here as distinct poses, planar artwork and restrained local effects.
- [Jen Zee's firsthand Hades art interview](https://mcvuk.com/business-news/behind-the-art-of-hades-we-value-artistic-integrity-and-excellence-in-artistic-craft-at-supergiant-however-were-first-and-foremost-a-game-design-lead-team/): gameplay and narrative guide the art, including UI and effects. Applied here by removing the marketing-style numbered menu and matching the pilgrim's material language to the city.
- [Yudho's own portfolio](https://yudho.xyz/): texture and negative space support recognizable forms. Applied here as ragged silhouette, muted cloth and bone, with a small eye accent.
- [Official Silksong screenshots](https://hollowknightsilksong.com/): inspected for foreground/background separation and clear character silhouettes. No reference artwork was copied or bundled.

These sources informed decisions; they do not establish equivalent craftsmanship. The new art was inspected in the actual renderer. Automated checks establish asset isolation, menu access and runtime behavior; human assessment of animation and visual quality remains necessary.

## Exact generation prompt

Create a production sprite animation atlas for an ORIGINAL dark pixel-art 2D side-view horror game called MOONPAW. Asset only, transparent background, no scenery, no text, no labels, no grid lines, no drop shadows. Wide canvas exactly 2:1 aspect ratio, 8 equal columns by 4 equal rows = 32 evenly spaced square sprite cells. Every cell has one full-body character facing RIGHT, consistent body size, consistent palette, consistent center/pivot; ample transparent padding separates all cells. Character is a FERAl CLOAKED CAT, genuinely feline elongated crouched anatomy with rear hocks, clawed forepaws, long expressive tapering tail, sharp swept-back ears and a narrow haunted muzzle. It is NOT a humanoid stick figure, NOT chibi, NOT a cute mascot. Tattered charcoal mantle across shoulders, ragged cloth panels with individually drawn folds, a small brass collar with a broken circular charm, pale scar along cheek, two tiny cold turquoise eyes. No cross symbols, no horns, no existing game character. Restrained ink-black, bone-white and gray palette with one subdued cyan eye accent; mottled armor-like scab texture and torn cloth, crisp deliberate pixel clusters, sharp stair-step edges, clear negative-space silhouette. High-detail pixel art, looks authored for a serious indie horror game. Avoid smooth vector gradients, blocky rectangular limb placeholders, 3D renders or generic fantasy armor. Each square cell has the same baseline near its bottom and same sprite scale. CELL ORDER left-to-right top-to-bottom: row1: 2 subtle breathing IDLE poses followed by RUN cycle poses1 through6. Row2: RUN cycle poses7 through14. Row3: RUN cycle poses15 and16, then rising JUMP, falling JUMP, then 4 clearly distinct curled spinning ROLL poses. Row4: 3 sweeping CLAW STRIKE poses (anticipation, extended forward attack, recoil), then compressed LANDING, HURT recoil, collapsed DEATH, clinging WALL pose, final subtle IDLE pose. Run cycle: agile but weighty, front/rear paws articulate in clear contact/passing/extension/tucked phases, feet travel backwards while planted, brief flight, spine compresses and extends, tail and cloth follow with delayed overlapping action. Rolling poses are an actually curled creature with tail wrapping around torso. Never draw repeated identical poses to fill cells. Consistency across all 32 illustrations is essential. Each complete sprite stays entirely in its own cell. Main body should occupy around 65% of cell width and 70% of cell height.
